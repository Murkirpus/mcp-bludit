# mcp-bludit

MCP-сервер для [Bludit CMS](https://www.bludit.com/) в одном PHP-файле. Подключает Claude и другие MCP-клиенты к сайту на Bludit и даёт им управлять страницами, категориями, тегами, медиа, пользователями, настройками, плагинами и темами.

Главное отличие от коннекторов к API-плагину: `mcp-bludit.php` работает **внутри ядра Bludit**. Он загружает движок так же, как `index.php`, и выполняет все изменения штатными функциями: `createPage()`, `editPage()`, `deletePage()`, `createCategory()`, `editUser()`, `editSettings()`, `activatePlugin()`, `activateTheme()` и другими. Поэтому всё работает так же, как при правке из админки:

- срабатывают хуки плагинов (`afterPageCreate`, `afterPageModify`, `afterPageDelete`), и плагины sitemap, кеша и SEO обновляются сами;
- пересчитываются индексы тегов и категорий;
- каждое действие записывается в журнал syslog от имени пользователя;
- проверяются роли admin / editor / author;
- JSON-файлы в `bl-content/databases` напрямую никто не трогает.

## Требования

- Bludit **3.22.x**. Писалось и тестировалось на 3.22.0 (BrownBear); на других версиях 3.x может работать, но не проверялось.
- PHP 7.4+ (проверено на PHP 8.3).
- Расширение GD — для загрузки и сжатия картинок.
- cURL — по желанию, для загрузки файлов по ссылке.

## Установка

1. Положите `mcp-bludit.php` в корень сайта Bludit, рядом с `index.php`.
2. Возьмите токен пользователя: **Админка → Пользователи → профиль → «Токен аутентификации»**. Нужен токен пользователя, а не токен API-плагина.
3. Подключите MCP-сервер в клиенте.

**Claude (claude.ai, приложение)**, пользовательский коннектор:

- URL: `https://example.com/mcp-bludit.php`
- заголовок: `Authorization: Bearer <токен>`

**Claude Code:**

```bash
claude mcp add --transport http bludit https://example.com/mcp-bludit.php \
  --header "Authorization: Bearer <токен>"
```

Проверка с сервера:

```bash
curl -s -X POST https://example.com/mcp-bludit.php \
  -H 'Authorization: Bearer <токен>' \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"ping"}'
# {"jsonrpc":"2.0","id":1,"result":{}}
```

## Авторизация

Токен принимается тремя способами:

| Способ | Пример | По умолчанию |
|---|---|---|
| Заголовок Bearer | `Authorization: Bearer <токен>` | включён |
| Свой заголовок | `X-Bludit-Token: <токен>` | включён |
| Параметр URL | `?token=<токен>` | **выключен** |

Токен в URL попадает в логи веб-сервера, поэтому по умолчанию он выключен. Включается настройкой `MCP_ALLOW_QUERY_TOKEN`.

Все действия выполняются от имени владельца токена и с его ролью:

- **admin** — всё;
- **editor** — любые страницы, теги, медиа, порядок страниц;
- **author** — только свои страницы и их файлы.

Отключённый пользователь сразу теряет доступ.

> Bludit при смене пароля выдаёт пользователю новый токен. Поэтому свой пароль через коннектор поменять нельзя: доступ пропал бы посреди работы. Меняйте его в админке и обновляйте токен в настройках клиента.

## Настройки

В начале файла:

```php
define('MCP_ALLOW_QUERY_TOKEN',  false);             // true — разрешить ?token=... в URL
define('MCP_ALLOWED_IPS',        '');                // через запятую; пусто = любые IP
define('MCP_MAX_DOWNLOAD_BYTES', 25 * 1024 * 1024);  // лимит файла, скачиваемого по URL
define('MCP_DOWNLOAD_TIMEOUT',   30);                // таймаут скачивания, секунд
```

## Сжатие картинок

`bludit_images_optimize` пережимает уже загруженные картинки штатным классом Bludit `Image`.

- Файлы сохраняются под **прежними именами**, поэтому ссылки в статьях и обложки не ломаются.
- JPEG и WebP пережимаются с качеством `quality` (по умолчанию 82). PNG сжимается без потерь.
- `max_width` пропорционально уменьшает слишком широкие картинки. Миниатюры только пережимаются, их размер не меняется.
- Файл заменяется, только если стал меньше хотя бы на `min_saving`% (по умолчанию 10). Повторный запуск уже сжатые файлы не трогает.
- Оригиналы копируются в `bl-content/mcp-backup/<дата-время>/` (параметр `backup`, по умолчанию включён).
- `dry_run: true` только показывает, сколько места освободится.
- Область: одна страница (`page`), общая папка uploads (`scope: common`) или всё (`scope: all`).
- Файлы обрабатываются порциями (`limit`, по умолчанию 100). Если в ответе есть `next_offset`, вызовите инструмент ещё раз с этим `offset`.
- Пропускаются GIF (сохраняется анимация), SVG, изображения больше 40 Мп и JPEG с EXIF-поворотом (иначе фото легло бы боком).

## Что исправлено по сравнению с прямыми вызовами ядра

У некоторых функций Bludit 3.22 есть особенности, которые форма админки обходит, отправляя полный набор полей. Коннектор делает то же самое:

- `editPage()` без поля `custom` затирает пользовательские поля страницы. Коннектор всегда передаёт текущие значения.
- `editPage()` без `parent` переносит дочернюю страницу на верхний уровень. Коннектор передаёт текущего родителя.
- `editSettings()` с неполным набором полей сбрасывает домашнюю страницу. Коннектор дополняет запрос текущими настройками.
- Media Manager сохраняет файлы с именами вида `name-jpg.jpg`. Коннектор сохраняет нормальное имя.

## Безопасность

- Сравнение токена через `hash_equals()`. Сессии и cookie не создаются: «вход» существует только в памяти на время запроса.
- Загрузка по URL — только http(s). Адреса локальных и служебных сетей блокируются (защита от SSRF).
- Тип картинок проверяется и по расширению, и по MIME. Файлы принимаются только из списка разрешённых Bludit.
- Пути удаляемых файлов проверяются, выйти за пределы папки загрузок нельзя.
- Весь вывод ядра и плагинов перехватывается и не ломает JSON-ответ.
- Можно ограничить доступ по IP (`MCP_ALLOWED_IPS`).

Если перед сайтом стоит антибот или WAF с JS-проверкой, добавьте `/mcp-bludit.php` в исключения. Иначе клиент получит страницу проверки вместо JSON.

## Протокол

MCP Streamable HTTP: JSON-RPC 2.0 через `POST`, ответ `application/json`, без SSE. Поддерживаются `initialize`, `ping`, `tools/list`, `tools/call` и пакетные запросы. Версии протокола: `2025-11-25`, `2025-06-18`, `2025-03-26`, `2024-11-05`.

## Решение проблем

| Симптом | Причина |
|---|---|
| 401 / клиент просит «войти» | Неверный токен, отключён пользователь, токен передан в `?token=` при `MCP_ALLOW_QUERY_TOKEN = false` или заголовок `Authorization` не доходит до PHP (попробуйте `X-Bludit-Token`) |
| 405 | Открыли адрес в браузере (GET). Сервер принимает только POST |
| HTML вместо JSON | Запрос перехватил антибот или WAF |
| Картинки не загружаются | Нет GD, нет прав на запись в `bl-content/uploads` или `bl-content/tmp` |
